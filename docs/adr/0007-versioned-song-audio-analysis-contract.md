# ADR-0007: Song/Audio 实验方向

- Status: Superseded
- Date: 2026-08-03
- Superseded: 2026-08-03 by the TempoMap-driven Arrangement model

Song import、audio playback、waveform、automatic analysis 和 A/V calibration 不属于当前 Lumina Authoring V1。TempoMap 是 Arrangement 的确定性音乐时钟能力，不表示音频资源或分析能力。

当前时间模型见 [`0003-musical-time-and-timeline-evaluation.md`](0003-musical-time-and-timeline-evaluation.md) 与 [`../authoring/arrangements.md`](../authoring/arrangements.md)。
